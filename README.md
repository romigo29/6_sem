# 6_sem

Материалы шестого семестра: лабораторные работы, практические задания и проекты по профильным дисциплинам.

## Дисциплины

| Аббревиатура | Полное название | Основные технологии |
|---|---|---|
| ИБ | Информационная безопасность | Основы криптографии (Python) |
| ПИС | Программирование интернет-сервисов | Go |
| ПСКП | Программирование серверных кроссплатформенных приложений | Node.js |
| ПиРБДИП | Проектирование и разработка баз данных интернет-приложений | Oracle Database (вариант 12 – «Управление лицензиями на ПО») |
| ТПО | Тестирование программного обеспечения | Unit-, API- и UI-тестирование (Python, JavaScript) |
| ТРВП | Технологии разработки веб-приложений | NGINX, Docker |

# Текстовая стеганография на Python

Приложение реализует два способа скрытия сообщения в DOCX-документе:

1. модификация расстояния между строками;
2. модификация кернинга / межсимвольного интервала.

## Структура проекта

- `main.py` — точка входа;
- `gui.py` — графический интерфейс tkinter;
- `docx_stego.py` — алгоритмы внедрения и извлечения сообщения;
- `binary_codec.py` — перевод текста в биты и обратно;
- `file_service.py` — чтение `text.txt` / `text.docx` и сохранение результата;
- `config.py` — настройки приложения;
- `text.txt` — пример текстового контейнера;
- `requirements.txt` — зависимости.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Логика кодирования

Сообщение переводится в UTF-8. Перед полезной нагрузкой добавляется 32-битный заголовок, в котором хранится длина сообщения в байтах.

Для кернинга используется правило:

- бит `0` — обычный межсимвольный интервал;
- бит `1` — расширение межсимвольного интервала на 1 pt.

Для межстрочного интервала используется правило:

- бит `0` — интервал 12 pt;
- бит `1` — интервал 14 pt.

Результат сохраняется в файл `encoded_output.docx` в одной директории с `main.py`.
